How it works

JSON uses JSON.stringify/JSON.parse for correct escaping of quotes, backslashes and control characters. C escapes/unescapes the common C-string sequences (\n \t \r \\ \" \0 and hex/octal-style bytes). URL uses encodeURIComponent/decodeURIComponent. HTML escapes the five reserved characters (& < > " ') to named entities and decodes named/numeric entities back to text. Everything runs locally in your browser.
